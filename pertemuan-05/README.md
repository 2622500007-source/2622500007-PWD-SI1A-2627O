# Pertemuan 5 - JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Implementasi

- Mengembangkan halaman web menggunakan JavaScript untuk menambahkan interaksi pada halaman.
- Menggunakan DOM untuk mengakses dan memanipulasi elemen HTML.
- Menggunakan event listener untuk menangani interaksi pengguna.
- Menambahkan validasi formulir sisi klien untuk memeriksa data yang dimasukkan pengguna.
- Menggunakan JavaScript untuk mendukung interaksi navigasi dan formulir.

## Fitur dan Pengembangan

- JavaScript: Menambahkan fungsi interaktif pada halaman web.
- DOM: Mengakses dan memanipulasi elemen HTML sesuai kebutuhan.
- Event listener: Menangani aksi pengguna pada elemen halaman.
- Validasi formulir: Memeriksa input pengguna sebelum formulir diproses.

## Pengujian

- JavaScript: Menguji fungsi JavaScript dan memastikan kode berjalan tanpa kendala.
- DOM dan event listener: Menguji interaksi pengguna dan memastikan elemen merespons sesuai fungsi yang dibuat.
- Validasi formulir: Menguji formulir untuk memastikan validasi berjalan sesuai ketentuan.
