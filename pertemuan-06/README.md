# Pertemuan 6 - PHP Dasar dan Pemrograman Sisi Peladen

## Implementasi

- Mengembangkan halaman web dari proyek Pertemuan 5 (P5) dengan menambahkan PHP.
- Mengubah halaman utama dari `index.html` menjadi `index.php`.
- Menggunakan variabel, konstanta, tipe data, dan operator PHP untuk menghasilkan konten dinamis.
- Menerapkan struktur percabangan `if-elseif-else`, `switch-case-default`, dan operator ternary.
- Menggunakan perulangan `for` dan `while` untuk menampilkan daftar secara dinamis.
- Menggunakan fungsi bawaan PHP seperti `number_format()` dan `date()` untuk mengolah serta menampilkan data.
- Menjalankan dan menguji halaman PHP melalui Laragon dan `localhost`.
- Mengelola perkembangan proyek menggunakan Git dan GitHub.

## Fitur dan Pengembangan

- **PHP Dasar:** Menggunakan sintaks PHP, `echo`, dan `print` untuk menghasilkan keluaran dinamis.
- **Variabel dan Konstanta:** Menampilkan informasi mahasiswa, mata kuliah, tahun akademik, dan profil GitHub.
- **Tipe Data dan Operator:** Menggunakan tipe data dasar serta operator untuk melakukan perhitungan dan pemeriksaan kondisi.
- **Percabangan:** Menentukan keterangan semester, nama program studi, status mahasiswa, dan fokus program studi berdasarkan kondisi.
- **Perulangan:** Menampilkan lima target belajar menggunakan `for` dan tiga nomor semester menggunakan `while`.
- **Fungsi Bawaan PHP:** Memformat tampilan IPK, memeriksa nilai `NULL`, dan menampilkan tahun secara dinamis pada footer.
- **Formulir:** Menyesuaikan atribut `action` dari `index.html` menjadi `index.php`.
- **Integrasi Proyek:** Mempertahankan struktur, stylesheet, JavaScript, gambar, dan fitur P5 yang masih digunakan.
